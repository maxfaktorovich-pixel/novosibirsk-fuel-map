# Заправки Новосибирска — OpenStreetMap

Интерактивная карта АЗС Новосибирска на основе данных OpenStreetMap.

## Как запустить

1. Склонируйте репозиторий
2. Откройте `index.html` в браузере

Или залейте файлы на любой статический хостинг (GitHub Pages, Netlify, Vercel и т.д.).

## Возможности

- Карта всех АЗС из OSM
- Поиск по названию/бренду
- Геолокация
- Локальные отметки о наличии топлива и ценах (localStorage)
